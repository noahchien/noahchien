## 工作裡，我把事情接起來

證券風控與交易、信託服務、保險給付平台，都是我走過的領域。從需求、架構和開發，到測試與交付，我喜歡看見零散的環節，慢慢接成一套能運作的系統。

主要使用 **Java／Spring、C／C++、Node.js、Python**，也有 **Git、Docker、Jenkins** 與DevOps協作經驗。經歷包含康和證券、中國信託、富邦人壽及資策會；交通大學資訊工程系畢業。
